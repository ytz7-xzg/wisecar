933ebb52aa35b4a6d6eedfe1634d7b6307893d98（只有 README）。

## 保留的能力

- pigpio 初始化和 PWM 写入：封装成唯一底盘输出，显式返回失败。
- 原舵机 PD、限幅、前视距离估计、地面平行边界的方向误差计算。
- 灰度/Canny 预处理、Hough 左右边界提取、蓝色挡板占比检测。
- 带外部标定参数的去畸变、摄像头采集、仅显示图像的调试入口。

## 边界和接口

- C++11；基础控制库无 OpenCV/pigpio 依赖；视觉和实车后端可分别启用。
- Chassis 通过 PwmDriver 操作硬件；构造不通电，open() 只写停车值和舵机中位。
- PWM 范围检查、初始化失败清理、写入失败停机、关闭时尽力回到中位。
- SteeringPD::compute(error_deg, pwm) 只计算。保留逐采样差分语义，调用方固定周期。
- ImageLine 表示图像 y=m*x+b；GroundLine 表示地面 x=m*y+b，二者不能混用。
- 地面坐标映射待实车标定后再接入；不迁移旧 60x320 查表和无边界检查的索引。
- 视觉无 GPIO/线程/比赛流程；空帧产生无效结果，不能当成挡板消失。
- 不带旧版变道、起步冲量、定时制动、5G协议、比赛状态机或自动驾驶入口。
- 本次运行的是编译和软件测试，不连接实体车、不创建实车实验目录。

## 验收

无硬件测试覆盖底盘初始化/写入失败、范围限制、PD重置及非有限输入、地面几何有效性。
有 OpenCV 时验证空帧、纯色挡板、道路丢失无旧结果、去畸变独立输出。
README 给出两种构建方式、视觉调试命令、来源映射和实车未标定项。
