# our_car 底座迁移实施计划

> 执行：本会话直接实现；用户已授权提交 our_car。

**Goal:** 提取可独立编译、可验证、可供三人协作调用的基础控制和视觉模块。
**Architecture:** 控制计算与 PWM 后端分离；视觉只接收图像并返回检测结果。
**Tech Stack:** C++11、CMake 3.10、可选 OpenCV 4、可选 pigpio。
**Spec:** ../../base-design.md

## 全局约束

- 沿用 main 的算法和参数来源；所有机械参数明确标记待实车核对。
- 本次只提交 our_car，基于已读取的最新分支提交，不强制覆盖远端。
- 默认禁用真实 GPIO 后端；提供仅计算示例与仅视觉调试入口。

## 检查重点

- 初始化某一步失败后，不能继续写行驶指令。
- NaN/无效几何/空图像必须返回失败，不能留下有效旧结果。
- 电机和舵机范围、引脚重复、非法配置须在启用硬件前拒绝。
- 丢线后返回无效新观测；图像线与地面线的类型和单位分开。
- 检测器对常见不同尺寸输入工作，去畸变要求与标定分辨率一致。
