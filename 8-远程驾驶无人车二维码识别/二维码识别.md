# 二维码识别

**1、案例前软件安装**

   1.1安装libzbar-dev

```
sudo apt-get install libzbar-dev
```

   1.2安装pyzbar

```
pip3 install pyzbar
```

安装完成后，按照如下图步骤进行操作

如果没有报错，说明安装成功

**2、案例步骤**

   2.1 打开目录 

```
cd /home/pi/test_img
```

   2.2 上传测试文件find.py和data.txt，其中data.txt用于存储识别数据。

   2.3 输入以下指令

```
python3 find.py
```

识别成功自动关闭窗口识别到的内容保存在data.txt文件中
